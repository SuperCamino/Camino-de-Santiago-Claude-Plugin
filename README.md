# SuperCamino: Camino de Santiago Planner

Plan the Camino de Santiago with Claude, using SuperCamino's route data.

## What it does

- **Plan a Camino day by day:** tell the assistant where you want to start and how many days you have, and it suggests where to stop each night, with the distance and climb of every day, using the towns pilgrims usually stay in.
- **Check a stage:** how far and how hard a day is, the climb, and the towns along the way.
- **Find places to stay:** albergues, hotels, and other places to stay in a town, with links.
- **Choose a route:** a short comparison of the Camino routes for the time you have, ending with a plan.

Every plan comes with a link that opens it in SuperCamino's free planner and map, where you can move stops, add rest days, and save it. Free to use, no sign-up needed to plan.

Routes covered: Camino Francés, Portugués (central and coastal), del Norte, Primitivo, Inglés, Finisterre and Muxía, the Spiritual Variant, and the Via Podiensis.

## Use it

Ask in your own words, in English, Spanish, French, German, Italian, or Portuguese. For example: "I want to walk from Sarria in 5 days, where should I stop each night?", "How hard is Saint-Jean to Roncesvalles?", or "Albergues in Roncesvalles?".

## Data

The plugin sends the place names, number of days, dates, and language you ask about to SuperCamino's server at supercamino.com/mcp. It sends nothing about you, needs no account, and stores nothing on your device. SuperCamino keeps a log of the questions asked (no personal data) to improve the service. Privacy policy: https://supercamino.com/privacy/
